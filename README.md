#OPEN REPOSITORY
My project is called Open Repository.
It is a full-stack web application developed using the MERN stack. The main purpose of this project is to manage the complete academic project submission process digitally.
In colleges, students usually submit their projects through email, pen drives, physical copies, or other manual methods. This creates problems such as difficulty in managing files, losing project data, tracking project status, and maintaining old projects.
So, we developed a centralized system where students can submit projects, teachers can review them, and administrators can manage the academic information.
